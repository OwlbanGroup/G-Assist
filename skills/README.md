# G-Assist skills

Agent skills for Project G-Assist. This directory is the source of truth for the NVIDIA skills catalog.

| Skill | What it does |
| --- | --- |
| [g-assist-mcp-skill](g-assist-mcp-skill/SKILL.md) | Check or change this machine's NVIDIA display and GPU settings through the G-Assist MCP server. |
| [plugin-builder-skill](plugin-builder-skill/SKILL.md) | Generate new G-Assist Protocol V2 plugins from a natural-language spec using an interactive interview and the CLI generator. |
